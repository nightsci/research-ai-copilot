## Git 与安全范围

原目录和部署目录均不是 Git 仓库，没有跟踪文件或本地提交历史可审查。因此“历史扫描”是**不适用**，不是已经证明所有历史绝对无密钥。未创建本地提交、远程仓库或执行上传。未来初始化仓库后可重复运行 `python -m scripts.audit_release`，它会检查已跟踪文件和可达历史 blob。

`.gitignore` 排除 `.env`、实际 secrets.toml、虚拟环境、上传目录、验收产物、PDF 和常见私人文档格式。忽略规则不能清除已经跟踪的文件，不能抵抗强制添加。常见模式及已知值扫描也不能识别一切形式的秘密，需要在提交前复核暂存清单。

## 费用与上传

生成默认关闭。开启后共享服务端密钥可能被访客反复调用；当前没有账户鉴权、全局限流、并发配额或硬预算，不能宣称已经具备收费 API 公共访问的防滥用保护。建议首次公开展示使用无密钥模式，收费演示放在访问受限环境并配专用低额度密钥。

上传入口单文件 20 MB；应用进一步限制最多 3 文件、合计 30 MB、每文件最多 200 页及文字量上限。有加密、损坏、扫描版和超限提示。未实现 OCR、恶意 PDF 隔离解析或完整资源耗尽防护。
