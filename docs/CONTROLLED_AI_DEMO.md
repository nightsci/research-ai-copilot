# 受控 AI 演示方案（仅设计，尚未实施）

日期：2026-10-29。当前公网继续无模型密钥运行，不因本方案自动开启收费调用。优先展示真实本地录屏，面试时由作者操作本地模型；只有确需邀请访客自行问答时，再实施独立受控部署。

## 服务端访问控制

公网证据版继续保持现状；受控版使用单独部署和专用服务端密钥。使用 OIDC 登录，服务端按可信身份的 issuer + subject 检查邀请白名单、失效时间与撤销状态。登录只证明身份，必须另做授权；隐藏按钮、URL 参数及浏览器状态均不能作为授权依据。[Streamlit 官方认证说明](https://docs.streamlit.io/develop/concepts/connections/authentication)

每次模型 HTTP 调用前统一执行授权、配额与预算检查。改写、生成、引用重试、全文范围核查全部经过同一入口。未登录、权限过期、账本不可用或模型价格未审核时拒绝收费请求，保留证据检索。服务端固定模型与 API 域名，拒绝用户传入密钥或任意 API 地址。人工开启演示窗口，结束后关闭总开关并撤销邀请。

## 共享额度和费用硬上限

首轮建议策略（并非已配置值）：每人每日 5 次问答、全部用户每日共 30 次；单人并发 1、全局并发 2；每日人民币 5 元、整个演示活动总预算 20 元。次数与金额限制同时生效，先达到者为准。

1. 使用持久化 PostgreSQL 事务账本，记录活动、日期、用户、请求唯一 ID、预留金额、结算金额与状态。所有进程/会话共享，不能使用 session_state、内存字典或云端临时磁盘计数。唯一约束防止重复提交，行锁/原子事务防止并发超额。
2. 入场时原子预留问答次数；每次 HTTP 请求再预留最坏费用：`输入 token 上界 × 未缓存输入单价 + 最大输出 token × 输出单价`。计入系统提示、JSON 和引用开销，只允许有经验证 token 上界、输出上限和价格版本的模型。不能把中文字符数当 token 数，也不能假定缓存折扣。不确定上界时拒绝调用。
3. 事务内同时检查当日与活动的“已结算 + 在途预留 + 本次预留”不超过预算，成功后才发送。限制输入、输出及每题模型请求数（建议最多 4 次），每次重试也申请额度。全文核查可因预算不足而跳过，但需明确返回证据不足。
4. 成功响应按 usage 结算并释放差额。超时、断网、未知计费或崩溃时保留最坏费用，不自动退款或自动重试；重启后由管理员核对账单再调整。跨日结算归原预留日期。价格变化时停止调用直到重新审核。
5. 管理员总开关立即停止新请求；在途请求已预留，仍在硬上限内。新增会话、重启、换实例和更换邀请都不重置活动总预算。

上述硬上限以所有请求经过统一入口、token/价格上界正确且密钥未泄露为前提。当前代码没有预算账本；勾选框、告警与余额轮询不是硬限额。DeepSeek 的 [余额接口](https://api-docs.deepseek.com/api/get-user-balance/) 用于监控，不提供本应用的原子预算预留。上线前需在服务商后台实际确认是否支持可强制执行的账户支出限制；若支持，设为不高于活动预算并验证拒绝行为。独立低余额账户、关闭自动充值只是额外保护，未经验证不能宣称绝对封顶。无法证明费用上界与拒绝机制时，继续采用录屏或作者在场演示，不开放共享收费接口。

## 密钥保护和风险

密钥仅存于受控服务端 Secrets，不进入 Git、浏览器、提示词、日志或录屏。日志仅记录匿名用户 ID、请求 ID、时间、状态、token 与预算，不记录 Authorization、问题、全文或回答。定期轮换专用密钥，泄露时先撤销再处理历史。无模型密钥不代表服务不处理文档：PDF 仍在服务器解析；启用模型前需告知文本将发送至服务商。

残余风险包括账号转借、PDF 资源耗尽、提示注入、供应商计费变化及模型推理错误。邀请制不替代上传限制与引用校验；摘录存在也不证明结论正确。保留原文展示及拒答，不能通过放宽证据阈值提高演示成功率。

## 实施顺序和放行验收

先实现统一调用守卫与持久化账本，再接入身份提供商，最后在隔离部署注入低额度专用凭据。依次验证：

- 未登录、非白名单、过期邀请直接触发请求时均不调用模型。
- 两会话争抢最后额度仅一个获准；重复 ID 不重复发送；重启和新实例不重置额度。
- 改写、生成、引用重试、范围核查全部受控；超时和崩溃不释放未知计费预留。
- 达到金额/次数上限、数据库故障或关闭总开关时停止请求，原文证据仍可用。
- 用小额真实 API 对照 usage 和账本验证结算、停止行为；检查日志、网络返回及 Git 中无凭据。

这些测试与真实小额验证全部通过后，才由作者批准开放。当前没有执行上述步骤，也未验证服务商账户硬限额。
