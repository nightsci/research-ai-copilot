# 工作台 UI/UX 优化验收

日期：2026-10-29。范围：独立部署目录中的界面、主题、UI 测试及说明文档。未更改学术查询、PDF 解析、TF-IDF 评分、RAG 服务、模型 HTTP 请求或引用校验模块；运行依赖不变。

## 设计与交互

- 统一 Research AI Copilot 品牌标题与“科研文献智能工作台”副标题；青绿主按钮、深蓝文字、浅色背景和白色卡片。
- 原生横向导航使用“文献检索 / 论文阅读”，隐藏多余标签；保留 feature_page key 并兼容旧页面值。
- 搜索框聚焦主任务，年份折叠到高级筛选；侧栏仅留来源与折叠的取回数量设置。计数来自真实结果，期刊过滤、导出及部分失败提示保留。
- 文献卡片统一标题、作者、年份、期刊、来源及查看论文入口；DOI 和来源记录折叠。
- 阅读页按上传、提问、结果组织；解析成功前不显示提问区。示例为说明文字，不伪装成可点击按钮。无模型时不显示生成操作，提示英文关键词限制。
- 证据卡片显示真实来源编号、论文名、物理页码与原文；相似度放入检索详情。默认不显示哈希、偏移或调试 JSON。模型回答仍可展示，引用折叠以便核查。
- UI 保留上传限制、外部模型文本发送告知、拒答和真实错误；没有配置任何收费密钥。

## 自动化与真实验证

全部 **84 项通过，4.78 秒**：原有 78 项按新文案更新 UI 断言，业务测试全部保留；新增 6 个 UI 场景覆盖全来源失败、空结果、标题转义及 DOI/年份传递、损坏 PDF、显式生成与证据操作分离、无依据问题。模型场景使用离线桩，不代表真实 API 回答；本轮未调用收费模型。

本机 Edge 无头浏览器在 1366×900 与 390×844 下执行真实页面操作，检索空态、阅读空态及测试 PDF 的解析/原文结果均无页面异常、无横向溢出。移动端侧栏自动收起。真实搜索 `polysilazane corrosion coating` 本次返回 50 条、合并后 44 条、当前显示 44 条，非模拟响应；数量随上游数据变化。

PDF 浏览器验收使用明确标注 `UI-TEST-ONLY.pdf` 的合成夹具，仅验证上传、解析和证据显示，不用于宣传科研结论。真实截图与浏览器记录保留在被 Git 忽略的 `artifacts/ui-review/`，不把测试文档、私人 PDF 或凭据上传仓库。桌面/移动浏览器视口验收不等于所有实体手机兼容性已验证。

## 安全和交付边界

静态 CSS 只使用语义元素与应用自己指定的 key 类，不插入用户内容、不依赖自动生成类名。论文标题继续 HTML 转义，作者、原文与模型文本安全显示。没有新增大型运行依赖；浏览器测试工具仅在项目外的验证环境安装。

提交前执行完整测试、凭据/历史扫描及 Git diff 审查，只提交本次 UI 和说明文件。云端是否已更新必须以推送后的公网检查为准，不能由本地测试或 GitHub 推送推断成功。真实问答演示视频仍未提供；本轮不增加视频链接。
